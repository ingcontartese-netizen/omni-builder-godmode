# INVARIANTS

1. One payload writer at a time.
2. Builder and verifier evidence lanes remain distinct.
3. Inputs are frozen, hashed, and rechecked after verification.
4. Silence is never consent; interrupted verification is inconclusive.
5. UI selection grants no lease.
6. Predecessor is fenced and quiescent before successor lease.
7. Host version, surface ID, model, reasoning effort, permission surface, tools, and roots are restored exactly.
8. Agentic, script, and host-context sentinels are rehydrated and read back.
9. No opaque AI self-spawn or blind create-once retry.
10. F5, installation, publication, and external effects remain closed.
11. Exactly one script supervisor exists per project root; its canonical namespace is derived from that root, and alternate state directories never create another legitimate supervisor.
12. One project has one well with two separately restorable brains and non-overlapping builder/verifier knowledge lanes; no shared file is co-written.
13. User material never replaces mandatory current web research; mandatory research creates an obligation to seek authority, not authority itself.
14. `NETWORK_RESEARCH` and `DOWNLOAD` are separate effect grants. Without download authority, use `CAPTURE_MD_ONLY`; never execute quarantined downloads.
15. Each lane freezes its light map, deep plan, dossier, and source manifest before reading peer synthesis; `NO_ORACLE_CONTAMINATION_BEFORE_LANE_FREEZE` is mandatory.
16. Knowledge fusion begins only after both `LANE_FROZEN` receipts and the PM-reserved `KNOWLEDGE_FUSION` gate. Builder authors and a distinct verifier session countersigns exact bytes.
17. Fusion preserves provenance, conflicts, dissent, exclusions, uncertainty, and unresolved gaps; disagreement is never erased to manufacture consensus.
18. No realization plan, fused program, Mode selection, or execution is canonical before `KNOWLEDGE_FUSION_PASS`.
19. `PM_RELAY` can transport exact bytes but is neither the governed channel nor an independent countersignature.
20. `GUIDED_PM` leaves reserved transitions with the PM and arms no automation by implication. `AUTONOMOUS` requires a bounded autonomy envelope plus a separate explicit `ARM_AUTOMATION` grant, named sentinels, budgets, stops, and kill switch.
21. Progressive activation is invariant: knowledge may be available without invocation, invocation may occur without effect authority, and a stronger Mode or module is never inferred from capability or complexity.
